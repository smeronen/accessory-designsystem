# accessory-ds
A small accessible-first design system built with Web Components. Components are documented in Storybook, and have example packages in React and Angular.

## Packages
- `@accessory-ds/tokens` - design tokens and theme styles.
- `@accessory-ds/components` - Web components.
- `@accessory-ds/react` - optional React wrappers.
- `@accessory-ds/angular` - optional Angular wrappers.
